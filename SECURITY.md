# 安全策略 / Security Policy

## 报告安全问题 / Reporting a Vulnerability

发现安全问题时，请**不要**公开创建 Issue。请通过 GitHub 的私有漏洞报告通道提交：

**仓库页面 → Security → Advisories → Report a vulnerability**
（[GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities)）

Please do **not** open a public issue for security vulnerabilities. Report them privately via
**Security → Advisories → Report a vulnerability** on this repository.

维护者会尽快确认收到报告，并与你沟通修复与披露安排。
