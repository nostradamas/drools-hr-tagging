# 验收规格说明书

## A1. 编译验收
- [A1.1] `mvn clean compile` 通过，无 ERROR
- [A1.2] `mvn clean test` 通过，测试全部 GREEN
- [A1.3] `npm run build` 通过（前端）

## A2. 规则管理验收
- [A2.1] 创建规则 → 自动生成 DRL → 编译通过 → 可用
- [A2.2] 更新规则 → 重新编译 → 新规则生效
- [A2.3] 禁用规则 → 不再触发
- [A2.4] 删除规则 → 从引擎移除
- [A2.5] 规则验证 → 语法错误提示准确
- [A2.6] 规则导出 → 导入 → 规则完整还原

## A3. 标签库验收
- [A3.1] 创建标签 → 可在标签列表查到
- [A3.2] 按维度/分类筛选 → 结果正确
- [A3.3] 标签导入 → 导出 → 数据完整

## A4. 员工标签验收
- [A4.1] 员工打标签 → 触发对应规则 → 标签正确分配
- [A4.2] 标签过期 → 自动失效
- [A4.3] 按维度统计 → 数量正确

## A5. 岗位匹配验收
- [A5.1] 员工A匹配职位B → 分数在 0-100 区间
- [A5.2] 技能完全匹配 → 得分 ≥ 80
- [A5.3] 技能完全不匹配 → 得分 < 60（不推荐）
- [A5.4] 批量匹配 → 按分数降序排列
- [A5.5] 推荐接口 → 只返回 recommended=true 的结果

## A6. 非功能性验收
- [A6.1] API 响应格式统一 {success, message, data, timestamp}
- [A6.2] 异常返回标准错误码
- [A6.3] 跨域配置可访问
