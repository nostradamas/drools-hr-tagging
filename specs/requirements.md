# 需求规格说明书

## 1. 项目定位
Drools Rules Engine — 基于 Drools 规则引擎的规则管理与智能匹配系统。
面向需要将业务规则从硬编码中解耦的开发团队，提供规则管理、标签体系、智能匹配一站式能力。

## 2. 用户角色
- **管理员**：规则全生命周期管理、标签库维护
- **HR/业务人员**：查看员工标签、执行匹配分析
- **开发者**：通过 REST API 集成规则引擎能力

## 3. 模块范围

### 3.1 规则管理模块
- 规则 CRUD（创建/读取/更新/删除）
- 规则模板引擎（7 种预置模板）
- 动态规则编译与热加载
- 规则语法验证
- 规则的启用/禁用
- 规则批量操作
- 规则导入/导出

### 3.2 标签库管理模块
- 标签 CRUD
- 标签分类管理（3 维度 15 分类）
- 标签搜索
- 标签批量操作
- 标签统计分析
- 标签导入/导出

### 3.3 员工标签模块
- 多维度自动打标签（能力/履历/考评）
- 规则引擎驱动的智能标签分配
- 标签过期自动管理
- 标签置信度评估
- 标签变更历史
- 标签统计分析

### 3.4 岗位匹配模块
- 员工 ↔ 岗位智能匹配
- 多维度评分（技能/经验/学历/薪资/管理经验）
- 推荐策略（高度推荐/一般推荐/不推荐）
- 批量匹配
- 匹配结果分析与导出

## 4. 业务规则
- 标签来源分为：RULE_ENGINE（规则引擎）、MANUAL（手动）、SYSTEM（系统）
- 标签按维度设置有效期：考评类 6 个月、能力类 1 年、履历类 2 年
- 匹配分数 ≥ 60 分视为匹配，≥ 80 分视为高度推荐
- 规则优先级 1-10，优先级越高越先执行
